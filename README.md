# Python Data Analyzer

A beginner-friendly Python project that analyzes numerical data and generates summary statistics.

## Features

- Counts the number of values
- Calculates the total and average
- Finds the median
- Identifies the highest and lowest values
- Calculates the range
- Validates input data and handles empty lists
- Organizes the code into reusable functions

## Technologies

- Python 3
- Python standard library

## Getting Started

### Requirements

Install Python 3 on your computer.

### Run the project

1. Clone this repository:

```bash
git clone https://github.com/qhawe-ntanga458/python-data-analyzer.git
```

2. Open the project folder:

```bash
cd python-data-analyzer
```

3. Run the program:

```bash
python data_analyzer.py
```

Depending on your system, you may need to use `python3` instead of `python`.
