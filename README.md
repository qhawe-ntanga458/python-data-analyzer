# Python Data Analyzer

## About
A beginner Python project that analyzes numerical data and calculates basic statistics.

## Features
- Counts the number of values.
- Calculates the total.
- Calculates the average.
- Identifies the highest value.
- Identifies the lowest value.

## Technologies
- Python
- Built-in functions: sum(), len(), max(), min()

## Learning Goals
- Variables
- Lists
- Arithmetic
- Built-in functions
- Printing results
